TEAMSpeak HEERLEN 3D CAFE — VOLLEDIG PROJECT v0.8
==================================================

BELANGRIJK: Zie START-HIER-COMPLETE-v0.8.md voor alle stappen.

1. Pak deze ZIP uit.
2. Ga naar GitHub: https://github.com/michiel66/TS-Heerlen-3D-Cafe
3. Upload in EEN KEER de uitgepakte INHOUD (alle bestanden en mappen).
4. Commit changes. GitHub Actions bouwt de Windows Setup.exe.

De enige avatarbron is Polygonal Mind 100Avatars R1 (CC0).
GitHub Actions downloadt automatisch de echte modellen tijdens de build.
Dat betekent dat de 3D-modellen NIET fysiek in deze broncode-ZIP zitten.

NIET de ZIP rechtstreeks uploaden als een enkel bestand: GitHub pakt die
niet vanzelf uit. De mapstructuur moet behouden blijven.

TS audio/PTT: de build herstelt de laatst geverifieerde TeamSpeak-sources
van jouw eigen bestaande GitHub-commit voor het bouwen.
